# ClickIt Faster

Форк [Barragek0/ClickIt](https://github.com/Barragek0/ClickIt). Репозиторий — **ClickIt-Faster**, отображаемое имя в меню — **ClickIt Faster**. DLL, namespace/InternalName и профиль остаются **ClickItMax** для совместимости с текущей установкой. В старой сборке меню ещё показывает ClickItMax; новое имя появится после следующей сборки. Оригинальный ClickIt держите выключенным при использовании форка.

## Подбор и запрет дальнего ухода

Быстрый режим выбирает ближайший допустимый предмет по свежему world/grid XY расстоянию. История кликов действует только как временный запрет повторного клика по тому же ground ID+Address. После истечения таймера предмет снова конкурирует наравне с новым. Ползунок повторов: **10–500 мс**, default100.

Пока внутри **«Радиуса без ходьбы»** остаётся хотя бы один подходящий предмет на полу, команды к целям дальше **«Дистанции для movement»** запрещены: и обычный клик для ходьбы, и movement-скилл. Недавний клик и cooldown этот запрет не снимают. Автоматического таймаута ожидания нет. Уже известные предметы проверяются по ground entity-list даже при скрытой подписи. Пороги берутся из настроек: при23/40 уход дальше40 ждёт исчезновения последнего near-предмета. Цели между23и40 остаются допустимыми. При movement-пороге ниже near-радиуса ближний подбор не блокирует сам себя.

Две галочки независимо управляют hover-проверками ближних и дальних кликов. Остановка подхода освобождает выбор цели, но не доказывает подбор. Отпускание hotkey прекращает новые команды; уже принятую игрой ходьбу не отменяет. Periodic Toggle Item View дважды нажимает выбранную клавишу, обычноZ, по настроенному интервалу.

## Movement

Приоритет доступных скиллов: Flame Dash → Frostblink → Leap Slam → Whirling Blades → Dash → Blink Arrow → Lightning Warp → Shield Charge. Каждый можно выключить. Все8поддерживаемых скиллов удерживают свою привязку до нового собственного action или расхода заряда, максимум **80 мс**, polling5мс. IsUsing/Stage сами по себе не подтверждают старт. Есть cancellation/finally и независимый watchdog key-up. Подтверждение старта не означает прибытие.

FD использует общий интервал850мс после ручного/автоматического применения. «Ждать Flame Dash на ходу, мс» допускает ожидание заряженного готового FD во время подхода;0отключает. Восстановление отсутствующего заряда не прогнозируется. На цель одна movement-попытка за удержание hotkey. Для Dash настройте соответствие Always Attack Without Moving. Неопределённый Lightning Warp ограничивается до смены области.

## Установка и проверка

Сборка и пути установки описаны в [README.md](README.md). DLL: `Plugins/Compiled/ClickItMax/ClickItMax.dll`; профиль: `config/global/ClickItMax_settings.json`; звук: `config/ClickItMax/alert.wav`. Файлы ядра Host не заменяйте библиотеками из исходников форка.

Последняя логика подбора/movement прошла122focusedMSTest; distance-only selection также прошёл23независимых motion traces. Это локальные проверки, не статус CI и не весь унаследованный suite. 12октября2026пользователь сообщил о заметно более стабильном подборе и меньшем числе пропусков после near-ground guard. Измеренного универсального ускорения или гарантии всех подборов нет.

Переименование в UI добавлено только в исходники: по запросу пользователя новая DLL пока не собирается и не публикуется. Проверка нового имени и совместимости профиля в следующей живой сборке ещё предстоит.

Диагностика: `Logs/ClickItMax/pickup-*.jsonl`. Есть target-selected, near-ground-departure-blocked/released, movement-input-hold и bounded movement-cast-diagnostic для всех8скиллов, включая причины отпускания/acknowledgement, action/charges/позиции. Логи ограничены очередью/ротацией; отсутствие записи не всегда означает отсутствие события. Перед передачей своих логов проверьте содержимое.
